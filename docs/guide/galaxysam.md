# GalaxySAM: galactic chemical evolution

A Python implementation of a semi-analytic model for galactic chemical
evolution and stellar nucleosynthesis, converted and extended from a set of
IDL routines. It is independent of the dust microphysics in `models/` — it
supplies the metal enrichment history that dust models consume.

The API reference is at {doc}`/api/galaxysam`.
