# Repository layout and package guide


```
pyproject.toml  MANIFEST.in  LICENSE  requirements-dev.txt
src/pycalima/
  _paths.py         where everything is read from and written to
  _datasets.py      reference-dataset registry and fetcher
  _provenance.py    code-revision stamping for generated tables
  plotting_style.py opt-in matplotlib styling
  models/           physics and export logic
  solvers/          ODE and steady-state solvers
  galaxysam/        semi-analytic galaxy chemical evolution
  data/             bundled read-only reference data
    external_data/  literature rates, cross-sections, SEDs
    optical_props/  dielectric functions and optical constants
    registry.toml   dataset declarations
diagnostics/        script-style physics checks (check_*.py)
notebooks/          tutorials
tests/              pytest suite
reference_data/     large PAHdb archives (gitignored, not bundled)
```

Paths in the sections below are relative to `src/pycalima/` unless noted.

## Core code

- `models/`
	- Main Python package with all physics and export logic.
	- The central configuration is `models/grain_size_distribution.json`.
	- `models/grain_size_config.py` loads configuration and exposes helper accessors used by almost all modules.

## Input data

Read-only and bundled inside the package, so it is available wherever pycalima
is installed. Access it through `pycalima._paths`, never by path arithmetic.

- `data/external_data/`
	- Literature and calibration tables used by model computations (cross sections, rates, yields, potentials, etc.).
	- `_paths.get_external_data_path("henke", "f1f2_Henke.dat")`

- `data/optical_props/`
	- Reference optical datasets (Draine-Lee, Li-Draine, and others) used to interpolate grain/PAH optical properties.
	- `_paths.get_optical_props_path("li_draine_2001", "PAHneu_30")`

- `data/registry.toml`
	- Declares every reference dataset, its provenance and whether it is bundled,
	  fetchable or must be obtained manually. See `calima-fetch-data list`.

## Output data

Generated, never bundled. Resolved per call, so it honours `$CALIMA_DATA` and
the active configuration's `model_name` — see {doc}`/getting-started/data-locations`.

- `model_data/`
	- Precomputed output tables for cooling, sputtering, charging, heating, and optical properties.
	- Regenerated by `calima-export`. Location: `_paths.get_model_data_dir()`.

- `results/`
	- Solver output and figures. Location: `_paths.get_results_dir()`.

## Chemistry solver

- `solvers/`
	- Self-contained Python ODE solver for dust and PAH mass evolution.
	- Reads pre-computed tables from `model_data/` and initial conditions from a JSON config.
	- Supports time integration (adaptive RK4) and direct steady-state (Newton–Krylov, sparse Newton).
	- Can run single-point or a parallelised 2-D parameter grid.

## Tests, diagnostics and setup utilities

Paths in this subsection are relative to the repository root, not the package.

- `tests/`
	- The pytest suite, covering installation, data locations and each source
	  section. See {doc}`/development/testing`.

- `diagnostics/check_config.py`
	- Quick sanity check for reading an alternative grain-size configuration.

- `diagnostics/stromgren_test/`
	- Stromgren test utilities and setup files for simulation experiments.

- `diagnostics/<subpackage>/check_*.py`
	- Script-style physics checks that produce figures.

## Tutorials

All notebooks live in `notebooks/`, with outputs cleared.

- `notebooks/calima_tutorial.ipynb`
	- End-to-end walkthrough of the solver workflow (single-point RK4 and equilibrium runs, T–nH grids, plotting).

- `notebooks/calima_dust_pah_processes.ipynb`
	- Deep dive into individual dust and PAH physical processes, rate-table inspection, and isolated-process runs.

- `notebooks/ramses_equilibrium_tutorial.ipynb`, `notebooks/CALIMA_model_explorer.ipynb`
	- RAMSES post-processing and parameter-space exploration. Both need the `sim`
	  extra (`yt`).

# Package Guide: What Each Section Does

The `models/` package is organized by physical domain. Paths are relative to
`src/pycalima/`; as an import path, `models/dust_charge/dust_charging.py` is
`pycalima.models.dust_charge.dust_charging`.

## Global and shared modules

- `models/constants.py`
	- Shared constants used across modules.

- `models/dust_model.py`
	- High-level accessors to build grain/PAH distributions from configuration metadata.

- `models/grain_distributions.py`
	- Distribution classes (lognormal, power-law with cutoff, and variants).

- `models/grain_size_config.py`
	- Config loader and API for bins, parameters, and export options from JSON.

- `models/export_all_grain_data.py`
	- Master orchestration script to regenerate all precomputed datasets under `model_data/`.

## Dust-focused subpackages

- `models/dust_radiation/`
	- Optical properties and radiative processes.
	- Includes interpolation of dust efficiencies/cross-sections, extinction-related utilities,
		RATD tools, dust emission utilities, and optical-property exporters.

- `models/dust_charge/`
	- Dust charging and photoelectric heating.
	- Includes equilibrium charge distribution solvers, Coulomb enhancement models,
		shared charging physics, and table exporters for charging/heating rates.

- `models/dust_gas_collisions/`
	- Gas-grain collisional physics for dust.
	- Includes collisional cooling and sputtering calculations and their batch export scripts.

- `models/dust_collisions/`
	- Grain-grain collision outcomes.
	- Includes coagulation, shattering, and relative velocity models.

- `models/dust_chemistry/`
	- Dust-surface chemistry utilities.
	- Currently includes H2 formation related models and plotting helpers.

## PAH-focused subpackages

- `models/PAH_radiation/`
	- PAH optical properties and interpolation/export utilities.

- `models/PAH_charge/`
	- PAH charging and photoelectric heating models.
	- Includes ISRF-dependent heating efficiency table generation.

- `models/PAH_gas_collisions/`
	- PAH sputtering and destruction rates from gas collisions.
	- Includes exporters for PAH sputtering rate tables.

- `models/PAH_photophysics/`
	- PAH photophysics and dissociation (including acetylene-loss based tables and plots).

- `models/PAH_collisions/`
	- PAH-PAH and PAH-dust collisional/coalescence style models.

## Utility section

- `models/tools/`
	- Shared utilities (radiation field definitions, unit helpers, SED readers/checkers,
		and post-processing helpers for simulation outputs).

- `models/yields/`
	- Yield table-building helpers used by sputtering workflows.
