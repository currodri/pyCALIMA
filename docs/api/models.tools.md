# `pycalima.models.tools`

Shared utilities: radiation field definitions, Mie theory, atomic scattering
factors, RAMSES SED readers, unit helpers, and post-processing helpers for
simulation output.

`eq_analysis` imports `yt`, so it requires the `sim` extra
(`pip install 'pycalima[sim]'`).
