# `pycalima.galaxysam` — chemical evolution

A semi-analytic galaxy chemical-evolution model: an IMF, stellar and Type Ia
supernova yields, and the integrator that combines them.

Converted from IDL; the modules are thoroughly documented in NumPy style but
carry no type annotations.
