# Scripts and exporters

Not every module is part of the API. Of the 116 modules in the package, 29
reproduce figures or run diagnostics and 12 are batch exporters driven from the
command line. They are listed here rather than in {doc}`/api/index`, where they
would outnumber the physics.

The exporters are documented as commands in {doc}`/cli/calima-export`. The
figure and diagnostic scripts are research artefacts: most reproduce a
published figure, and each is runnable with `python -m <module>`. They carry no
stability guarantee.

This table is generated by walking the package and subtracting whatever the API
pages already list, so a new module cannot quietly go undocumented.
