# pyCALIMA

<p align="center">
	<img src="assets/CALIMA_logo1.png" alt="pyCALIMA logo" width="420"/>
</p>

pyCALIMA is a research codebase for modeling dust and PAH microphysics used in RAMSES simulations.
It combines grain-size distributions, radiation, charging, sputtering, collisional cooling, and
PAH-specific photophysics into reusable Python modules plus export scripts that generate simulation-ready tables.

## Related References

- RAMSES repository: https://github.com/ramses-organisation/ramses
- CALIMA model paper: https://ui.adsabs.harvard.edu/abs/2026arXiv260221790R/abstract

## What This Repository Contains

- Physics modules in `models/` for dust and PAH processes.
- Source/input tables in `external_data/` and `optical_props/`.
- Generated lookup tables in `model_data/`.
- Simulation setup and analysis helpers in `tests/stromgren_test/`.

This repository is script-first (not a packaged PyPI library yet): most workflows are run with
`python -m models.<module>` commands.

## Repository Layout

### Core code

- `models/`
	- Main Python package with all physics and export logic.
	- The central configuration is `models/grain_size_distribution.json`.
	- `models/grain_size_config.py` loads configuration and exposes helper accessors used by almost all modules.

### Input data

- `external_data/`
	- Literature and calibration tables used by model computations (cross sections, rates, yields, potentials, etc.).

- `optical_props/`
	- Reference optical datasets (Draine-Lee, Li-Draine, and others) used to interpolate grain/PAH optical properties.

### Output data

- `model_data/`
	- Precomputed output tables for cooling, sputtering, charging, heating, and optical properties.
	- Regenerated by export scripts in `models/`.

### Tests and setup utilities

- `test_config_check.py`
	- Quick sanity check for reading an alternative grain-size configuration.

- `tests/stromgren_test/`
	- Stromgren test utilities and setup files for simulation experiments.

## Package Guide: What Each Section Does

The `models/` package is organized by physical domain.

### Global and shared modules

- `models/constants.py`
	- Shared constants used across modules.

- `models/dust_model.py`
	- High-level accessors to build grain/PAH distributions from configuration metadata.

- `models/grain_distributions.py`
	- Distribution classes (lognormal, power-law with cutoff, and variants).

- `models/grain_size_config.py`
	- Config loader and API for bins, parameters, and export options from JSON.

- `models/export_all_grain_data.py`
	- Master orchestration script to regenerate all precomputed datasets under `model_data/`.

### Dust-focused subpackages

- `models/dust_radiation/`
	- Optical properties and radiative processes.
	- Includes interpolation of dust efficiencies/cross-sections, extinction-related utilities,
		RATD tools, dust emission utilities, and optical-property exporters.

- `models/dust_charge/`
	- Dust charging and photoelectric heating.
	- Includes equilibrium charge distribution solvers, Coulomb enhancement models,
		shared charging physics, and table exporters for charging/heating rates.

- `models/dust_gas_collisions/`
	- Gas-grain collisional physics for dust.
	- Includes collisional cooling and sputtering calculations and their batch export scripts.

- `models/dust_collisions/`
	- Grain-grain collision outcomes.
	- Includes coagulation, shattering, and relative velocity models.

- `models/dust_chemistry/`
	- Dust-surface chemistry utilities.
	- Currently includes H2 formation related models and plotting helpers.

### PAH-focused subpackages

- `models/PAH_radiation/`
	- PAH optical properties and interpolation/export utilities.

- `models/PAH_charge/`
	- PAH charging and photoelectric heating models.
	- Includes ISRF-dependent heating efficiency table generation.

- `models/PAH_gas_collisions/`
	- PAH sputtering and destruction rates from gas collisions.
	- Includes exporters for PAH sputtering rate tables.

- `models/PAH_photophysics/`
	- PAH photophysics and dissociation (including acetylene-loss based tables and plots).

- `models/PAH_collisions/`
	- PAH-PAH and PAH-dust collisional/coalescence style models.

### Utility section

- `models/tools/`
	- Shared utilities (radiation field definitions, unit helpers, SED readers/checkers,
		and post-processing helpers for simulation outputs).

- `models/yields/`
	- Yield table-building helpers used by sputtering workflows.

## Generated Data Structure

Key output folders inside `model_data/`:

- `optical_properties/`: dust and PAH averaged cross-sections per configured bin.
- `collisional_cooling_data/`: cooling tables versus gas temperature and charge state.
- `thermal_sputtering_data/`: dust sputtering tables (temperature/phi grids).
- `pah_sputtering_data/`: PAH sputtering tables and quicklook plots.
- `dust_charging_data/`: charge moments and related quicklook products.
- `dust_photoelectric_heating_data/`: dust photoelectric heating/cooling tables.
- `PAH_photoelectric_heating_data/`: PAH heating efficiency and ionization-state tables.
- `PAH_dissociation_data/`: PAH dissociation tables and contour-style plots.

See `model_data/README.md` for a generation-time report with metadata and export summary.

## Configuration Model

The file `models/grain_size_distribution.json` defines:

- Active bins (`bins`) with composition, PAH flag, and rank.
- Distribution parameters for each bin (`basic`, `shattering`).
- Export sampling parameters (`export_parameters`) used by batch exporters.

Most workflows read this file through `models/grain_size_config.py`, so changing it is the
primary way to adapt the model setup.

## Setup

No pinned environment file is currently provided in the repository root, so create a virtual
environment and install dependencies manually.

Example:

```bash
python -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install numpy scipy pandas matplotlib seaborn tqdm joblib unyt astropy yt swiftascmaps
```

Notes:

- Some modules are optional for specific workflows (for example `yt` for analysis scripts).
- If a script complains about a missing package, install it in the active environment.

## Usage

### 1. Run a quick configuration sanity check

```bash
python test_config_check.py
```

### 2. Regenerate all model tables

```bash
python -m models.export_all_grain_data
```

### 3. Run individual exporters

```bash
# Dust optical properties
python -m models.dust_radiation.export_dust_optical_properties

# PAH optical properties
python -m models.PAH_radiation.export_pah_optical_properties

# Dust collisional cooling
python -m models.dust_gas_collisions.export_collisional_cooling_bins

# Dust sputtering tables
python -m models.dust_gas_collisions.export_sputtering_rates_bins

# PAH sputtering tables
python -m models.PAH_gas_collisions.export_pah_sputtering_rates_bins

# Dust charging summary tables
python -m models.dust_charge.export_dust_charging_vs_gamma

# Dust photoelectric heating tables
python -m models.dust_charge.export_dust_photoelectric_heating

# PAH photoelectric heating tables
python -m models.PAH_charge.export_PAH_photoelectric_heating_tables

# PAH dissociation tables
python -m models.PAH_photophysics.export_pah_dissociation_tables
```

### 4. Use a custom configuration file

```bash
python -m models.export_all_grain_data --config path/to/your_config.json
```

Most exporter modules accept `--config` and read runtime defaults from the JSON
`export_parameters` block.

## Testing and Validation

- Quick validation: `python test_config_check.py`
- Stromgren setup utility: `python tests/stromgren_test/stromgren_setup.py --help`
- Several subpackages include script-style test files (`test_*.py`) that can be run directly.

## Current Status and Scope

- The repository is actively used as a scientific modeling workspace.
- `model_data/` already contains precomputed tables for configured bins.
- The codebase mixes reusable modules and experiment scripts; expected for research workflows.

If you are new to the project, start by reading:

1. `models/grain_size_distribution.json`
2. `models/grain_size_config.py`
3. `models/export_all_grain_data.py`

These three files define the data model, configuration API, and full export pipeline.
